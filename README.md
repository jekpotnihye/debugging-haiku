One haiku about debugging, in the 5-7-5 syllable shape, entered for the
[Seventeen Syllables of Debugging](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605)
competition on [make.fun](https://make.fun).

## The haiku

See `entry.txt`. The program in `main.ts` writes that same text to
`/output/entry.txt` when it runs.

## Run

Requires Node 22.18 or later:

```sh
node main.ts
```

It writes `/output/entry.txt` (creating `/output` if needed).
